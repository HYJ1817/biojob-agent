# BioJob Agent 0.1.0

首个可安装的 Windows 个人版，面向生物工程本科秋招。

主要功能：

- 生物医药岗位公开源、手工 JD 导入与去重；
- 带岗位详情/申请/招聘主页链接的投递管理；
- 基于已确认个人事实的 JD 匹配报告；
- Word/PDF 基础简历导入与人工确认；
- 针对“准备中”岗位的可追溯 Word 简历版本；
- 带超链接的四工作表 Excel 投递台账；
- 多模型 API 与原有 Agent 对话能力；
- 安装包内置项目源码，不依赖私有 GitHub 仓库完成首次安装。

安装前请阅读 `docs/BIOJOB_WINDOWS_GUIDE.md`。本版本未使用商业代码签名证书，Windows 可能显示“未知发布者”。
