# BioJob Agent Windows 安装与使用指南

## 1. 它是什么

BioJob Agent 是一个只在你自己的 Windows 电脑上运行的桌面求职工作台。当前版本重点服务生物工程本科秋招，适合制药生产/工艺、发酵、生物工艺、QA/QC、细胞培养、实验员和研发助理等岗位。

它可以：

- 从企业公开招聘页、RSS/公开检索源或手工粘贴的 JD 中收集岗位，并自动去重；
- 保留岗位详情页、申请页和企业招聘主页三个可点击链接；
- 依据已确认的个人事实生成有证据的岗位匹配报告，列出优势、缺口和建议；
- 管理从“考虑中”到“准备中、已投递、面试、Offer、结束”的投递状态，并保留变更记录；
- 导入 Word/PDF 基础简历，把识别出的内容放入“待确认事实”，不会直接写入正式简历；
- 为“准备中”的岗位生成 Word 简历版本，并记录所用事实、版本号和文件哈希；
- 导出带可点击链接的 Excel 投递表，包含投递总表、候选岗位、本周行动和数据字典；
- 继续使用原有 Agent 对话能力，并接入不同模型 API。

## 2. 安装条件

- Windows 10 或 Windows 11，64 位；
- 首次启动时保持网络连接，用于下载公开运行依赖；
- 建议预留至少 3 GB 磁盘空间；
- 不要求预先安装 Python、Node.js 或 Git，也不需要登录 GitHub；
- 使用 AI 对话和模型辅助功能时，需要你自己的模型 API Key。岗位导入、投递表、事实确认等本地功能不依赖付费模型。

安装包目前没有商业代码签名证书。Windows SmartScreen 若显示“未知发布者”，请先核对安装包 SHA-256；确认与发布页一致后，点击“更多信息”→“仍要运行”。

## 3. 安装

1. 从本仓库 Releases 下载 `BioJob-Agent-0.1.2-win-x64.exe`，并按发布页提供的信息核对文件大小和 SHA-256。
2. 双击安装包，按提示完成安装。
3. 启动 BioJob Agent。第一次启动会显示组件安装进度，通常需要几分钟；网络较慢时会更久，请不要直接关闭窗口。
4. 安装完成后，左侧导航点击“BioJob”进入求职工作台。

安装包已经内置本项目源码，因此首次启动不访问私有 GitHub 仓库。它仍会从公开官网/PyPI/npm 下载 Python、Node.js 与依赖包。

## 4. 首次配置模型 API

1. 在 BioJob 页面右上角点击“AI 设置”，或打开“设置 → Providers”。
2. 选择你要使用的模型提供商，填写 API Key、模型名和必要的 Endpoint。
3. 先发送一句简短测试消息，确认模型可以回复，再开始分析 JD。

可使用 OpenAI、Anthropic、Gemini、OpenRouter，以及兼容 OpenAI API 格式的服务。不同提供商实际可用的模型、费用和网络条件以其官方说明为准。API Key 由既有凭据配置机制保存，不写入 BioJob 的岗位数据库、简历或 Excel 文件。

## 5. 推荐工作流

### 第一步：建立个人事实库

打开“个人事实”。可以手工添加，也可以导入 `.docx` 或 `.pdf` 基础简历。每条事实都需要你选择：

- 确认：允许进入匹配或简历；
- 拒绝：明确不使用；
- 待确认：暂时不会用于正式输出。

同时检查可见范围。只有“简历”或“两者”且状态为“已确认”的事实，才可能写入生成的简历。

### 第二步：收集岗位

打开“岗位来源”：

- 点击“运行全部启用来源”，一次运行 10 组生物工程定向检索；
- 自动发现结果会进入“候选岗位”并标记“待核验”，先点击“打开原页面”确认时效和岗位要求；
- 在“官方核验入口”中可以直接打开 10 家重点药企/CRO/CDMO 的招聘主页；
- 添加公开招聘页或 RSS 源；
- 如果网页是动态页面、登录页面或抓取结果不完整，使用“手工导入”，粘贴公司、岗位、JD 和原始链接。

自动发现覆盖生产/工艺、QA/QC、细胞/实验、发酵/微生物、山东、大城市、高校就业网、重点药企、CRO/CDMO 和短期实习。官方入口包括齐鲁制药、荣昌生物、绿叶制药、华熙生物、康龙化成、药明康德、凯莱英、恒瑞医药、鲁南制药和鲁抗医药。搜索聚合结果可能过期或需要登录，必须通过保留的原始链接人工复核。

### 第三步：筛选并建立投递记录

在候选岗位中查看城市、公司、岗位和来源链接，点击“保留岗位”。这只创建“考虑中”记录，不代表已经向企业提交。

准备投递时，把状态改为“准备中”。只有在你确实完成外部提交后，才手工改成“已投递”。

### 第四步：JD 匹配和简历定制

1. 打开目标岗位，生成匹配报告；
2. 核对报告引用的事实、匹配优势和能力缺口；
3. 补充或修正事实后可重新生成报告；
4. 将岗位置为“准备中”，点击“生成简历”；
5. 在资源管理器中打开生成的 `.docx`，做最后排版检查后再投递。

系统不会捏造项目、实习、论文或技能。每个简历版本都保留所使用事实的快照，之后修改事实不会悄悄改写旧版本。

### 第五步：导出投递表

在“投递管理”点击“导出 Excel”。导出的 `.xlsx` 包含：

- 投递总表：状态、日期、跟进时间、岗位与公司；
- 候选岗位：尚未进入投递流程的岗位；
- 本周行动：需要跟进的事项；
- 数据字典：字段和状态说明。

JD、申请入口、企业招聘主页、匹配报告和简历文件均保留为可点击链接。

## 6. 数据位置与备份

默认数据保存在：

```text
%LOCALAPPDATA%\BioJob Agent\biojob\
```

其中包含 SQLite 数据库、导入文档副本、生成的简历与 Excel 文件。卸载桌面程序时不要假设这些求职数据会自动删除；重装或升级前，建议先完整复制 `biojob` 文件夹作为备份。

BioJob Agent 使用独立的运行环境和数据目录，不会复用或修改 `%LOCALAPPDATA%\hermes` 中已有的 Hermes 安装。若旧版 BioJob 曾在 `%LOCALAPPDATA%\hermes\biojob` 保存数据，新版首次启动会把该文件夹复制到上述新位置并保留原文件作为备份；Hermes 的 `config.yaml`、`.env`、认证信息、聊天记录和运行时不会被迁移。

请不要公开上传含有姓名、电话、邮箱、教育经历或 API Key 的文件。导出的简历和投递表属于个人敏感资料。

## 7. 当前边界

- 不登录招聘网站，不绕过验证码或反爬措施；
- 不自动点击“投递”，不代替你确认外部提交结果；
- 公开网页适配器是辅助发现工具，不保证覆盖所有岗位；
- 动态招聘系统可能只能保留入口链接，此时用手工导入补全 JD；
- 当前安装包为个人使用的未签名版本，不提供静默自动更新；升级时下载新版本安装包覆盖安装，并先做好数据备份。

## 8. 常见问题

**第一次启动一直在安装组件怎么办？** 先保持窗口和网络连接。若明确失败，记录界面显示的阶段和错误，重新启动会从可复用的阶段继续。

**某个来源显示失败怎么办？** 其他来源仍会继续运行；可稍后重试，并通过“官方核验入口”人工查看。网络代理/TUN 环境已兼容受审查的内置检索域名，但网站临时限制仍可能发生。

**岗位抓取结果是零条怎么办？** 点击“运行全部启用来源”后查看汇总；再打开企业招聘主页确认页面是否能正常访问。动态站点优先手工导入，不要把零条结果当作“没有岗位”。

**为什么简历按钮不可用？** 岗位必须处于“准备中”，并且事实库至少有可用于简历的已确认事实。

**为什么导入简历后没有直接生成新简历？** 导入内容默认是待确认状态，这是防止 OCR/解析错误和 AI 幻觉进入正式材料的安全设计。

**可以只用投递表，不配置 API 吗？** 可以。本地岗位、事实、状态流转、Word/PDF 导入和 Excel 导出可以独立使用；需要模型理解的对话功能才需要 API。
